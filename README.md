# CardioScan AI | Minimalist Cardiac Risk Engine

This project demonstrates an optimized Bio-AI pipeline that predicts the presence or absence of cardiac risk using a high-impact feature selection approach. It leverages a streamlined architecture built on the Cleveland Heart Disease Dataset and is deployed as an interactive clinical dashboard.

## 🚀 Project Overview
Rather than overwhelming the user interface with dense clinical parameters, this engine utilizes a **minimalist feature selection approach** to focus strictly on the core vitals. By filtering out feature noise, we created a highly response-driven, robust multi-dimensional coordinate field for real-time diagnostic mapping.

## 📊 Analytics & Model Performance
We benchmarked multiple predictive frameworks during exploration, finding that a spatial clustering approach yielded the sharpest mathematical boundaries for this clinical layout:

* **K-Nearest Neighbors (KNN):** 🏆 **90.16% Accuracy** (Current Production Model)
* **Logistic Regression:** 85.25% Accuracy
* **Gradient Boosting:** 77.05% Accuracy

### 🔍 Streamlined Feature Space (Core Vitals)
Using predictive feature evaluation, the interface was condensed down to the **5 most statistically significant biometrics** to maximize interface scannability and eliminate data entry lag:
1. **Age** (Patient Demographic Baseline)
2. **Sex** (Biological Marker)
3. **Chest Pain Severity (cp)** (Primary Symptomatic Signal)
4. **Serum Cholesterol (chol)** (Primary Metabolic Signal)
5. **Maximum Heart Rate Achieved (thalach)** (Cardiovascular Cap Limit)
